# Pegasus Insurance Platform

A comprehensive insurance management platform built with Angular and ASP.NET Core.

## Architecture

- **Frontend**: Angular 17 with Material UI
- **Backend**: ASP.NET Core Web API with Clean Architecture
- **Database**: SQL Server with Entity Framework Core
- **Infrastructure**: Azure Cloud Services

## Features

- Policy Management
- Claims Processing
- Document Management
- Reporting & Analytics
- Multi-tenant Architecture

## Getting Started

### Prerequisites

- Node.js 18+
- .NET 8 SDK
- SQL Server
- Azure CLI

### Development Setup

1. Clone the repository
2. Install frontend dependencies: `cd src/frontend && npm install`
3. Install backend dependencies: `cd src/backend && dotnet restore`
4. Run database migrations: `dotnet ef database update`
5. Start the application: `npm run dev`
